# AI Contribution Guidelines

This repository hosts a cryptocurrency trading system implemented in Python. To keep the codebase consistent and maintainable, follow these rules when making automated contributions:

1. **Coding style**: Use Python 3 syntax with four-space indentation. Keep lines under 120 characters.
2. **Documentation**: Every function and class must include a docstring describing its purpose, arguments, and return values.
3. **Formatting**: Format Python files using `black` before committing. The recommended command is `black .`.
4. **Linting**: Run `flake8` after modifications to ensure the code is clean. Install with `pip install flake8` if necessary.
5. **Updates**: Update `README.md` whenever behaviour or configuration changes.

Always run the style checks (`black` and `flake8`) before committing.
